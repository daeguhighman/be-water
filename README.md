# 물이 되어라

나쁜 습관을 끊는 108일. 하루가 지날 때마다 무대가 바뀌고, 발차기 하나를 만 번 연습함.

- 휴대폰을 가로로 들고 열기. 홈 화면에 추가하면 앱처럼 열림
- 워크맨: 이 기기에 있는 노래 파일을 골라 틀 수 있음(노래는 기기에만 저장되고 어디에도 올라가지 않음)
